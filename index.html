Overview

Intro

This functional requirements document covers the Agilent Applications & Industries template pages, reusable components, visible content types, user behavior, system behavior, authoring needs, data dependencies, responsive behavior, analytics considerations, and accessibility considerations.

Header and footer requirements are excluded. AI chat requirements are limited to placement only and remain marked as Pending AI Chat Focus Area where applicable.

Reusable Component Library: Cards + Rows

Reusable cards and rows that carry content, metadata, navigation, or product actions.

C01 · Card

Industry Card

PurposeHigh-level category entry card used on the Applications Hub landing template.
Content displayedIndustry/category title, short description, application count, image placeholder or image, and Explore CTA.
User behaviorUser selects the card or CTA to move into the corresponding category or filtered next-level view.
System behaviorSystem routes to the configured destination and carries category context where applicable.
Authoring RequirementsConfigure card title, description, count, image/alt text, CTA label, order, and destination.
Data DependenciesIndustry/category list; application counts by category; destination routes; approved image assets and alt text.
Analytics RequirementsTrack card ID, title, position, selected category, and destination.
Accessibility RequirementsCard and CTA need accessible names, visible focus, keyboard operation, and meaningful image alt text or decorative image flag.
Responsive BehaviorCards reflow from multi-column grid to stacked list while preserving title, count, and CTA.
Needs reviewFinal image assets and tablet/mobile card states were not available in the reviewed source.
